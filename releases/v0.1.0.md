# flatpak-sbom v0.1.0

Initial release of the Flatpak SBOM and vulnerability-reporting CLI, licensed
under GPL-3.0-or-later.

## Highlights

- Generate CycloneDX 1.7 SBOMs from commit-pinned Flatpak app/runtime manifests.
- Inspect installed or remote contents with Syft, including Electron ASAR
  packages, native-library evidence and corrected bundled VS Code extensions.
- Include selected extensions, discover host-enabled installed extensions and
  acquire checksum-verified remote extra-data without running install scripts.
- Scan with Grype and optional OSV package/commit queries, preserving scoped
  provenance and coverage gaps in reports.
- Quarantine known unreliable scanner identities rather than matching them as
  confirmed releases.

## Installation

Linux archives are provided for x86_64 and aarch64. They are built on Ubuntu
24.04 and require a compatible GNU/Linux userspace (glibc 2.39 or newer).
Verify downloads against `SHA256SUMS`, extract the archive and put
`flatpak-sbom` on `PATH`. Alternatively, build from the tagged source using
`cargo build --release --locked`.

The source archive includes the locked dependency sources, their licenses and
an offline Cargo configuration. Binary archives include third-party license
notices; the corresponding source is provided alongside them.

`ostree` is required for generation. Grype is required for vulnerability scans;
Syft is required for content scanning and Flatpak for installed input. Scanner
acceptance uses Syft 1.55.0 and Grype 0.121.0. `report` and `coverage` need no
external tools. See the README for commands and optional network requirements.

## Limitations

This is an initial, incomplete inventory tool, not a completeness or security
attestation. Stripped, statically linked and vendored dependencies may remain
unidentified. Vulnerability matches require triage and do not establish
exploitability or downstream patch status. Remote authenticity relies on HTTPS,
not OSTree GPG signature verification. The selected runtime is not necessarily
the historical build runtime. See `SECURITY-COVERAGE.md` for details.
